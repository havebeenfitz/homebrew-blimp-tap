# Blimp Homebrew Tap

Homebrew formulae for [Blimp](https://github.com/platacard/blimp) - a modern Swift CLI for iOS/macOS app deployment to TestFlight/App Store.

## Installation

```bash
brew tap havebeenfitz/blimp-tap
brew install blimp
```

## Updating

```bash
brew update
brew upgrade blimp
```
